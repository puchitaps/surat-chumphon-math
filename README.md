## หน้าเว็บมีอะไรบ้าง

แบ่งเป็น 3 แท็บ

- **ภาพรวม** — แผนที่ปักหมุดทั้ง 8 โรงเรียน (สีตามจังหวัด: เขียวน้ำทะเล = สุราษฎร์ธานี, ส้ม = ชุมพร)
  ตัวกรองจังหวัด / ระดับชั้น และการ์ดสรุปของแต่ละโรงเรียน
- **รายละเอียด** — ตารางเรียงตามลำดับที่ พร้อมเลขที่ตำแหน่ง แผนที่ย่อ ระดับชั้น และแหล่งอ้างอิง
  คลิกแถวเพื่อดูข้อมูลเต็ม: จำนวนนักเรียน/ครู ขนาดโรงเรียน ระยะทาง ห้องเรียนพิเศษ จุดเด่น ที่พัก ช่องทางติดต่อ
- **จัดอันดับ** — บทวิเคราะห์เขียนด้วยมือ ให้ดาวความเหมาะสม ข้อดี/ข้อเสีย และกล่อง "หลักการตัดสินใจ"
  เกณฑ์เรียงตามความสำคัญ: ความสะดวกในการเดินทางและใช้ชีวิต → ขนาดโรงเรียน/การเปิด ม.ปลาย
  → ห้องเรียนพิเศษ/ผลงานวิชาการ → ภาระงาน

## แหล่งข้อมูล

- รายชื่อโรงเรียนและเลขที่ตำแหน่ง: ประกาศบัญชีตำแหน่งว่าง สพม.สุราษฎร์ธานี ชุมพร (19 พ.ย. 2569)
- ข้อมูลประกอบอื่น ๆ (ที่ตั้ง พิกัด จำนวนนักเรียน/ครู ห้องเรียนพิเศษ ระยะทาง ที่พัก)
  ค้นจากแหล่งสาธารณะ — ทุกโรงเรียนมีรายการ **แหล่งอ้างอิง** แนบไว้ในตาราง
  ข้อมูลที่ยืนยันไม่ได้มีป้าย **"ไม่ยืนยัน"** กำกับ ควรตรวจสอบกับโรงเรียนโดยตรงก่อนตัดสินใจ

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ + CSS (Tailwind CDN, Leaflet, Google Fonts) |

## เปิดดูบนเครื่อง

เป็นเว็บ static ไม่มีขั้นตอน build — เปิดผ่าน local server ตัวใดก็ได้ เช่น

```bash
npx http-server . -p 8080
```

แล้วเปิด <http://localhost:8080>
