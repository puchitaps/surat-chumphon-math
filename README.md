## หน้าเว็บมีอะไรบ้าง

หน้าเดียว เรียงตามการตัดสินใจ หน้าตาแบบป้ายทางหลวงสีเขียว (มือถือเป็นหลัก)

1. **ป้ายเขียว: ตัวเลือกตอนนี้**: โรงเรียนอันดับแนะนำสูงสุดที่ยังว่าง พร้อมระยะทาง ขนาด ห้องเรียนพิเศษ
   กด **ถูกเลือกไปแล้ว** เมื่อมีคนเลือกโรงเรียนนั้นไปก่อน ป้ายจะเลื่อนไปตัวสำรองถัดไป
   (จำไว้ในเครื่องของแต่ละคน กดซ้ำเพื่อยกเลิก หรือ "ล้างที่ทำเครื่องหมาย")
2. **ถ้าเต็ม ไปทางนี้**: ตัวสำรอง 3 ลำดับถัดไปที่ยังว่าง
3. **ทั้ง 8 โรงเรียน ตามลำดับในประกาศ**: กดเพื่อดูข้อมูลเต็ม ข้อดี/ข้อเสีย และแหล่งอ้างอิง
   แถบใต้ชื่อคือระยะทางจากตัวเมือง สเกลเดียวกัน 0–90 กม.
4. **แผนที่**: วงกลมใหญ่ = นักเรียนมาก, เลขบนวงกลม = ลำดับที่ในประกาศ
5. **หลักการจัดลำดับ**: เกณฑ์และทางเลือกสำรอง

## แหล่งข้อมูล

- รายชื่อโรงเรียนและเลขที่ตำแหน่ง: ประกาศบัญชีตำแหน่งว่าง สพม.สุราษฎร์ธานี ชุมพร (19 พ.ย. 2569)
- ข้อมูลประกอบอื่น ๆ (ที่ตั้ง พิกัด จำนวนนักเรียน/ครู ห้องเรียนพิเศษ ระยะทาง ที่พัก)
  ค้นจากแหล่งสาธารณะ — ทุกโรงเรียนมีรายการ **แหล่งอ้างอิง** แนบไว้ในตาราง
  ข้อมูลที่ยืนยันไม่ได้มีป้าย **"ไม่ยืนยัน"** กำกับ ควรตรวจสอบกับโรงเรียนโดยตรงก่อนตัดสินใจ

## โครงสร้างไฟล์
